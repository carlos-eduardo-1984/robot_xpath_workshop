# The Power of QA - Workshop Setup

Welcome to The Power of QA workshop!

To ensure a smooth hands-on experience, all required tools and dependencies must be installed before starting the exercises.

## Prerequisites Installation
1. Open the folder setup_workshop.
2. Right-click on setup_workshop.bat and select "Run as Administrator".
3. Wait until the installation process completes.

The setup script will automatically install and configure the prerequisites required for the hands-on sessions, including:

- Python
- Node.js
- Required Python libraries and packages
- Required Node.js modules
- Additional tools and dependencies used throughout the workshop

## Verification

After the installation is complete, restart your terminal (Command Prompt or PowerShell) and verify that the tools are available:
```
python --version
node --version
npm --version
```
## Notes
- Administrator privileges are required for the installation.
- An internet connection is required to download the necessary packages.
- The installation may take a few minutes depending on your system and network speed.

Once the setup is completed successfully, you are ready to start the The Power of QA hands-on exercises.

Happy testing! 🚀
